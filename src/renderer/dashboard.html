가이드

처음 쓰시는 분들을 위한 준비 안내예요. 순서대로 따라하면 끝까지 연결할 수 있어요.

1
컴퓨터 사전 준비 (클로드 코드 설치 + Git)

전달받은 설치 파일(.exe)에는 이 프로그램을 실행하는 데 필요한 게 전부 들어있어서, Node.js 같은 건 따로 깔지 않아도 돼요. 다만 메일 요약·채팅 답변 같은 AI 기능은 이 컴퓨터에 별도로 설치된 클로드 코드(Claude Code)를 통해 동작하기 때문에, 아래 두 가지는 미리 준비해주세요. 클로드 코드를 처음 써보신다면 이 단계가 제일 중요해요.

① 클로드 코드(Claude Code) 설치: 윈도우 시작 메뉴에서 "PowerShell"을 검색해서 열고, 아래 명령어를 그대로 붙여넣은 뒤 Enter를 누르세요.
irm https://claude.ai/install.ps1 | iex
설치가 끝나면 같은 창에 claude --version을 입력해서 버전이 표시되는지 확인하세요. (참고: 클로드 코드는 무료 계정으로는 로그인이 안 되고, Pro/Max/Team 같은 유료 계정이 있어야 해요 — 사내에서 안내받은 계정으로 로그인하시면 됩니다.)

② Git: 클로드 코드가 명령을 실행할 때 함께 쓰기 때문에 설치해두는 걸 권장해요(없어도 동작은 하지만, 저희 팀에서 Git 없이 쓰다가 로그인 절차가 꼬였던 적이 있었어요). 아래 링크에서 내려받아 기본 설정 그대로 설치하면 돼요(특별히 바꿀 옵션 없이 "Next"만 눌러도 충분해요).
Git 다운로드 (git-scm.com)

(스크린샷 넣을 자리)
2
클로드 코드 로그인 + 폴더 신뢰 확인 (최초 1회)

1번에서 설치한 PowerShell 창에 claude라고 입력해서 실행해보세요. 처음 실행하면 브라우저가 자동으로 열리면서 로그인 화면이 나오니, 안내대로 로그인(승인)하면 됩니다. 로그인 후 터미널로 돌아오면 "이 폴더를 신뢰하시겠습니까?"(Do you trust the files in this folder?) 같은 확인 창이 뜨는데, 이때 승인해주세요.

이 확인은 폴더마다 보통 한 번만 하면 충분해요. 터미널 여는 법을 모르셔도 괜찮아요 — 아래 버튼을 누르면 이 프로그램이 대신 확인 창을 띄워드려요. 뜬 창에서 "Yes, I trust this folder"만 선택하시면 됩니다.

참고: 한 번 설치해두면 클로드 코드도, 이 두레이 어시스턴트 프로그램도 새 버전이 나올 때마다 알아서 업데이트돼요(따로 재설치할 필요 없음). 어시스턴트는 새 버전을 내려받아 두면 다음에 껐다 켤 때 적용됩니다.

(스크린샷 넣을 자리)
3
프로그램 설치하기

전달받은 설치 파일(예: "두레이 AI 어시스턴트 Setup x.x.x.exe")을 더블클릭해서 설치합니다. 설치가 끝나면 시작 메뉴/바탕화면에 아이콘이 생기고, 그 다음부터는 이 아이콘만 더블클릭하면 돼요. Windows가 "게시자를 알 수 없는 앱" 경고를 띄우면 "추가 정보" → "실행"을 누르면 됩니다.

(스크린샷 넣을 자리)
4
두레이 API 토큰 발급받기

두레이 웹사이트에 로그인 → 우측 상단 프로필 아이콘 클릭 → "개인 설정" → "API" 메뉴에서 토큰을 발급받을 수 있어요. 발급된 토큰은 복사해서 6번 단계(설정 탭)에서 붙여넣으면 됩니다. 토큰은 비밀번호와 비슷한 정보라 다른 사람에게 공유하지 않는 게 좋아요.

(스크린샷 넣을 자리)
5
두레이 주소(도메인) 확인하기

두레이에 로그인했을 때 브라우저 주소창에 보이는 주소예요. 예를 들어 "https://nhnent.dooray.com"으로 접속한다면, 입력할 값은 "nhnent.dooray.com"입니다 (맨 앞의 https:// 는 빼고 입력).

(스크린샷 넣을 자리)
6
"설정"에 입력하고 저장하기

오른쪽 위 설정 아이콘을 누르고, 위에서 확인한 두레이 주소와 토큰을 입력한 뒤 "저장"을 누르세요.

저장하는 순간 뒤에서 두 가지가 자동으로 진행돼요: ① 두레이 서버 연결, ② "MCP 도구" 등록. MCP는 클로드가 두레이의 업무·메일·캘린더 같은 실제 데이터를 답변에 활용할 수 있게 해주는 연결 통로예요. 터미널에 따로 명령어를 입력할 필요 없이 자동으로 처리되고, "로그"에 "두레이 MCP 도구 등록 완료"라는 문구가 뜨면 잘 된 거예요.

"홈" 화면에서 초록 불이 뜨면 정상적으로 연결된 것입니다.

(스크린샷 넣을 자리)
7
실제로 사용해보기

두레이 채팅방에서 "@두레이봇 질문"처럼 불러보거나, "메일" 탭에서 폴더를 골라 AI 요약을 확인해보세요.

특정 채팅방이나 메일 요약에서 유독 응답이 오지 않는다면, 2번 단계에서 신뢰해둔 폴더 범위 밖이라 그럴 수 있어요. 터미널에서 claude를 한 번 더 실행해 신뢰 확인을 해주면 대부분 해결됩니다.

(스크린샷 넣을 자리)
8
채팅에서 이렇게 시켜보세요 (명령어 모음)

전부 채팅방에서 @호출단어(기본: 두레이봇)를 붙여 말하면 돼요. 업무·일정을 실제로 바꾸는 명령은 실행 전에 봇이 꼭 한 번 되물어보고, "네"라고 답해야만 실행됩니다.

채팅으로 자동 생성되는 업무의 인사말(예: "안녕하세요. OO팀 OOO입니다.")에 채워질 고정 정보예요. 메일 요약의 [요청] 판단에도 이 이름이 쓰여요.

메일 전문 가져오기 (IMAP)

두레이 API는 메일 본문의 미리보기 일부만 줘서, 전체 내용을 보려면 IMAP 연결이 필요해요. 두레이 웹메일 → 설정에서 "IMAP 사용"을 먼저 켠 뒤 아래를 입력하세요. 비밀번호는 토큰처럼 자격 증명 관리자에 보관되고 파일로 남지 않아요.

두레이 로그인 비밀번호가 아니라, 웹메일 → 환경설정 → IMAP 화면에서 발급하는 전용 비밀번호를 넣어주세요. 저장된 값이 있으면 비워두면 그대로 씁니다.
캘린더 연동 (CalDAV)

일정 만들기가 계속 오류가 나서, 대신 CalDAV로 연동해요. 두레이 설정에서 발급한 CalDAV 비밀번호를 입력하세요. 서버 주소는 고정이라 따로 입력할 필요 없어요.

저장된 값이 있으면 비워두면 그대로 씁니다.
사내 LLM 연동 (Playground)

왓츠업(WhatsUp) 게시물 조회나 Harmony 휴가 기안 신청처럼 Playground에 이미 있는 기능이 필요할 때, 클로드가 이 정보로 Playground를 호출해서 대신 물어보고 답을 가져와요. 주소·모델명은 기본값이 채워져 있으니 보통은 API 키만 넣으면 돼요.

저장된 값이 있으면 비워두면 그대로 씁니다.
