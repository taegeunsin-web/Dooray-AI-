# 두레이 AI 어시스턴트

트레이 아이콘 형태로 상주하면서, 두레이 채팅방에서 "@두레이봇 질문"을 감지해 클로드 코드로
답을 만들어 보내주는 프로그램입니다. 태스크/위키/메일/캘린더/드라이브 도구는
클로드가 답변할 때 함께 쓸 수 있도록 MCP 도구로 내장되어 있습니다.

## 다운로드 / 설치

[GitHub Releases](https://github.com/taegeunsin-web/Dooray-AI-/releases/latest) 에서 최신
설치 파일 (AI.Setup.x.x.x.exe) 파일 하나만 다운로드해서 실행하세요.
(latest.yml, .blockmap 파일은 자동 업데이트용 내부 파일이라 무시하셔도 됩니다.).
새 버전이 나오면 이미 설치하신 분들은 앱을 켤 때 자동으로 업데이트됩니다.

Windows가 "게시자를 알 수 없는 앱" 경고를 띄우면 "추가 정보" → "실행"을 누르면 됩니다
(정식 서명(코드사인) 인증서가 없어서 나오는 정상적인 경고입니다).

### 처음 켤 때 — 두 가지만 준비

1. **클로드 코드(Claude Code) 로그인** — 이 컴퓨터에 클로드 코드가 설치되고 로그인까지
   되어 있어야 메일 요약·채팅 답변 같은 AI 기능이 동작합니다. 앱 안 "가이드" 탭에 설치
   명령어와 순서가 그대로 안내되어 있습니다. Windows에서는 Git도 함께 설치하는 걸
   권장합니다 — 클로드 코드가 내부적으로 사용합니다
   ([Git 다운로드](https://git-scm.com/download/win)).
2. **두레이 API 토큰** — 두레이 로그인 후 우측 상단 프로필 → 개인 설정 → API 토큰에서
   발급. 캘린더까지 쓰려면 CalDAV 전용 비밀번호도 추가, 메일 기능도 사용한다면 두레이 웹메일 → 환경설정 → IMAP
   화면에서 함께 준비하세요.

앱을 처음 켜면 뜨는 "설정" 화면에서 위 값을 입력하고 저장하면 끝입니다 (토큰은 이 컴퓨터의
OS 자격 증명 관리자에 안전하게 저장되고, 파일에는 남지 않습니다).

## 주요 기능

실행하면 "두레이 AI 어시스턴트" 대시보드 창이 자동으로 뜹니다. 창을 닫아도 프로그램은 트레이
아이콘으로 계속 상주해요. 오른쪽 위 설정 아이콘에서 두레이 주소/토큰을 입력하고 저장하면
자동으로 연결을 시작합니다 (처음이라면 앱 안 "가이드" 탭을 먼저 봐주세요).

- **채팅으로 업무 처리**: 두레이 채팅방에서 "@두레이봇 이번 주 내 태스크 뭐 있어?",
  "어제 온 메일 요약해줘", "그거 어떻게 됐어?"처럼 편하게 물어보면 답해줍니다. 멘션이 오면
  그 채팅방의 최근 대화를 두레이 API로 즉석 조회해서 맥락으로 함께 참고하기 때문에,
  프로그램이 꺼져있던 동안 온 대화도 포함해서 답할 수 있어요.
  <img width="1857" height="1097" alt="image" src="https://github.com/user-attachments/assets/55b2ac34-c88b-4b7f-b832-786783c0122e" />

- **템플릿 자동 연결로 업무 생성**: 채팅방을 프로젝트+템플릿에 미리 연결해두면, "@두레이봇
  태스크 만들어줘"라고만 해도 최근 대화 내용을 보고 템플릿을 채워서 자동으로 업무를
  만들어줍니다. 제목 접두사·기본 담당자·참고·태그도 미리 고정해둘 수 있고, 확실하지 않은
  항목은 추측하지 않고 비워두니 만든 후 두레이에서 한 번 확인해주세요.

  대시보드 달력에서 빈 날짜를 클릭해 새 일정을 등록하고 일정을 드래그해서 다른 날로
  옮길 수도 있어요

  [요청]으로 표시된 항목은 자동으로 "오늘 할 일"에 모여서 체크로 관리할 수 있어요. 지정한
  폴더에 새 메일이 오면 채팅방으로 AI 요약과 원문 링크를 자동 전송하는 알림도 설정할 수 있습니다.

  올리고, 멘션 없이 "회의 준비 끝냈어요"처럼 말만 해도 완료 처리되고, "7/29 메타 소재
  종료 예약"처럼 말하면 새 할 일로 자동 등록돼요. 사람별/업무 성격별로 태그를 나눠 보고
  드래그로 옮길 수 있고, 메일함에 쌓인 요청도 자동으로 포함시킬지 채팅방마다 켜고 끌 수
  있어요.

## 참고

- 아키텍처는 사내 오픈소스 Clauday(github.com/limtaewon/dooray-claude-gui-assistance,
  MIT 라이선스)의 Socket Mode / MessengerService / MentionDispatcher / 토큰 저장 방식(keytar) /
  채널별 작업폴더 분리 패턴을 참고했습니다. (2026-07-10 기준 README, package.json 실제 내용 확인)
- 두레이 메시지 조회 API(`/messenger/v1/channels/{id}/logs`)는 "최근 N개"까지만 지원하고,
  커서/기간 기반으로 그보다 더 과거까지 페이지를 넘기는 기능은 없습니다. Socket Mode 동시
  연결 불가 등 다른 제약은 이전에 만든 `dooray-mcp-server.js` / `dooray-bot-listener.js`에서
  이미 확인된 내용입니다.
